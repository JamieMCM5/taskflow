# Taskflow. 

This is a basic full-stack application that tracks tasks inputted from the user, stores them in a MySQL database and displays information like whether the task is completed, when it was created, and more.

## Features
- Add multiple tasks with descriptions.
- See information about tasks such as date created.
- Mark tasks as completed or ongoing.
